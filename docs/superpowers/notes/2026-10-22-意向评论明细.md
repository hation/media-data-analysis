# 交付记录 · 潜在客户意向评论明细（含视频地址）

> 日期：2026-10-22 → 2026-10-23
> 功能：为每条命中意向判定（score ≥ 2）的评论输出一行明细，携带所在视频标题/创作者/链接，按评论时间倒序
> 流程：brainstorming → 设计文档评审 → writing-plans → SDD 子代理执行（逐任务实现+评审）→ 全量重跑验证

## 需求来源
`潜在客户名单.csv` 只统计「所属视频数」，销售无法定位意向用户是在哪个视频下评论的，看不到视频语境、无法分析动机。需从评论反查视频。

## 实现内容
- `analyze.py` 新增「意向评论明细.csv」产出（插入在潜在客户识别之后、KOC 之前）：
  - 遍历去重评论按 `INTENT_PATTERNS` 打分，`score >= 2` 输出一行（与名单同口径）；
  - 按 `aweme_id` 关联视频表，带出 视频标题/视频创作者/视频链接；
  - `aweme_url` 为空回退 `https://www.douyin.com/video/<aweme_id>`；关联不到视频的评论三字段留空；
  - 按评论时间倒序；`运行摘要.txt` 追加 `意向评论明细: N 条`。
- `tests/test_intent_detail.py`：黑盒 TDD 测试（unittest + 子进程跑真实 analyze.py + 合成数据），覆盖 链接命中/空回退/视频缺失/无效时间戳/同用户多评论/名单≤明细/摘要行。
- `抖音数据销售分析说明.md`：3.4 结果导出、4 产出文件表同步；并顺手刷新 4 节既有基线数字（370→374、补明细 375 条）。
- 全量重跑新基线：`output/硬盘_douyin_202610231714`，与旧批次 `202610222138` 关键数字逐项一致（无副作用）。
